# Flower Image Classification with CNN

A beginner-friendly flower image classification project using Python, TensorFlow, and a convolutional neural network (CNN). The notebook walks through loading and preparing flower images, building and training CNN models, validating them, and exploring the flower dataset.

## Project contents

- `Vandana_Flower_Image_Classification.ipynb` - the project's notebook, including image loading and preprocessing, dataset visualization, CNN model training and validation, and a TensorFlow Datasets example.
- `LICENSE` - MIT License.
- `.gitignore` - common Python and Jupyter-generated files excluded from Git.

## Run the notebook

Open `Vandana_Flower_Image_Classification.ipynb` in Jupyter Notebook or JupyterLab and run its cells. The notebook uses Python libraries including NumPy, Pillow, TensorFlow, TensorFlow Datasets, and Matplotlib.

The notebook downloads the `flower_photos` archive from TensorFlow's public example-images URL when that dataset is not already available in the local Keras cache. The archive and extracted dataset are not included in this repository. A later notebook section also loads the `tf_flowers` dataset through TensorFlow Datasets.
